# 个人图书馆 · 界面草图（演示用）

**这是设计讨论用的可点击原型，不是可用系统。**
所有数据都是演示数据，没有连接任何真实文献库。视觉方向照 Notion 经典工作区：浅灰侧栏 + 白色画布 + 大标题页面头 + 数据库式列表。

## 怎么看

直接用浏览器打开 `index.html`（Chromium / Edge / Firefox，建议窗口 1440×900）。

- 无外部库、无外部字体、无网络请求；字体使用系统无衬线（Segoe UI / 微软雅黑 / Noto Sans SC）。
- 唯一的外部文件是两张真实页面图：`assets/ankang-775.png`、`assets/hanzhong-738.png`，相对路径引用。

## 界面结构

| 区域 | 内容 |
| --- | --- |
| 侧栏 240px | 工作区头像「文」+ 个人图书馆；分组「工作区」「专题」；页脚 本地工作区 / 设计预览 / 演示说明与限制 |
| 顶栏 45px | 面包屑「个人图书馆 / 全库检索」；右侧 研究助手、设计预览 · 演示数据、信息图标 |
| 页面头 | 32px 图标 + 32px 粗体标题 + 14px 说明；检索视图略浅，给阅读区留出空间 |
| 全库检索 | 数据库式视图行（全部结果 / 待核验）+ 右侧安静筛选 + 36px 检索框 + 搜索 / 别名扩展 |
| 结果列表 310px | 15px 标题 + 片段（命中的词有底色）+ 文件页 / 印刷页 + 状态标签 |
| 阅读区 | 文档标题、可展开书目属性、文件页与印刷页、原页扫描 / OCR 文本 / 对照标签页、底部来源条；属性默认折叠，为扫描页留空间 |
| 其余视图 | 全宽数据库 / 列表行；设置页为 Notion 式「标签 + 控件」行 |

响应式：≤1024px 侧栏收窄到 200px（仍显示文字导航，绝不出现 01–06 编号）；≤850px 侧栏变为可开合抽屉（顶栏 ☰），检索结果与详情单栏切换，详情内含「← 结果」；390px 宽度无横向溢出。

## 演示范围与限制

| 方面 | 本草图的做法 |
| --- | --- |
| 文献与文本 | 4 个示例文件、13 条页面记录，仅两页有真实页面图；其余为示意文本 |
| 字面检索 | 在示例文本上做真实的字符串查找，命中词有底色 |
| 别名扩展 | 预置的演示扩展（示例映射「文庙 → 孔庙」），没有向量检索，没有调用模型 |
| 识别任务 | 模拟条目与示例页数；暂停 / 继续 / 重试只改变显示，没有计时器自动推进 |
| 研究助手 | 模拟抽屉：预置回答 + 可点击的来源链接，全程无模型调用 |
| 扫描高亮 | 没有识别框坐标，因此扫描区不绘制任何文字框或高亮 |
| 导入 | 只读取所选文件的名称与大小；不读取内容、不上传、不联网 |
| API 密钥 | 设置页输入框为禁用状态，不接收、不保存、不发送 |
| 摘录与设置 | 仅存在于页面内存，刷新即回到初始演示状态 |

来源文字中含虚构占位内容，阅读区属性行与识别文本顶部都标注 **「示例文字 · 不可作为史料引用」**。完整限制见侧栏页脚「演示说明与限制」。

规模口径：示例文件合计 68 页；**验收目标：合计 1000 页（待测），分布在 3–5 个文件**，草图不假装已达到该规模。

## 可以走的几条路

1. 默认停在「全库检索」，检索词 `文庙`：左侧结果显示「文件第 7 页 / 印刷页 775」，右侧直接是原页扫描。
2. 点「别名扩展」：进入演示扩展模式，占位「孔庙」条目作为别名命中出现。
3. 视图行切到「待核验」：只保留尚未核验的页面。
4. 切到「对照」：左边原页、右边可读示例文本与校订备注；保存备注后相关摘录变为「已变更」。
5. 「保存摘录」→ 分类与备注 → 保存；到「摘录集」标记已核验、返回来源或删除（删除有确认，且可撤销）。
6. 顶栏「研究助手」：演示动作汇总 + 示例问答，来源链接可跳回对应页面。
7. 「识别任务」暂停 / 继续 / 重试；「文献库」导入（示例文件按钮不会打开系统选择框）；「设置」改服务地址与模型名称，并切换界面密度。
