# 网页摘录整理与资料导出验收

验收日期：2026-10-15 至 16（本机）。结论：本轮 Task 6 已通过独立验收。第一里程碑的历史结果保留在 [web-acceptance.md](web-acceptance.md)；本文件不代表网页 AI 研究或 1000 页性能已验收。

## 本轮交付

- 集合新建、改名、说明及按集合/来源/类别/核验状态筛选；摘录可属于多个集合。
- 本页全选、跨页保留选择、批量分类、加入或移出集合；改变筛选后清空选择。新条件加载失败时旧行继续禁用，避免操作错范围。
- 先预览数量与核验分布，再下载 CSV、JSON、Markdown 或 DOCX。全量导出不受列表 30 条分页限制；显式选择每次最多 500 项。
- 来源、分类和集合沿用列表；核验状态以导出窗口为准，默认只含已接受。选择全部状态时逐条保留提示。
- 引文、偏移、文字版本及记录时哈希来自保存的摘录；书目、当前页码和核验状态在一个数据库读事务中捕获。预览后资料变化返回 409 并重新预览。
- 导出文件按稳定 ID 下载，保留首次生成的不可变文件。写事务串行发布，处理并发、重复 DOCX 生成及提交失败清理。

资料集只整理保存的材料，不生成研究结论，也不把“摘录已接受”当作结论成立。
