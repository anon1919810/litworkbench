# 网页版使用说明

2026-10-16。本文件面向日常使用者，说明如何启动、导入、识别、检索、核对、整理与导出摘录。
命令行的老用法（`lit`）完全保留，两套界面共用同一个工作区与同一份数据。

## 一、启动

双击项目根目录的 `启动文献工作台.cmd`：

- 只监听 `127.0.0.1`，不对局域网开放；
- 浏览器自动打开 `http://127.0.0.1:8765/`；
- 默认数据目录是 `outputs\library`（在代码目录之外），可以在窗口里看到实际路径；
- **这个命令窗口就是后台服务窗口**：识别任务在窗口关闭后才会停止。
  要停服务，关闭窗口或按 `Ctrl+C`。

命令行等价写法：

```powershell
python -m litworkbench.web --workspace <数据目录> --port 8765 --no-browser
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `--workspace` | 数据目录；不存在会自动创建 |
| `--port` | 端口，默认 8765；被占用时自动顺延 |
| `--no-browser` | 不自动打开浏览器 |
| `--host` | 只允许 127.0.0.1；填其他地址会被拒绝 |

首次使用需要先装网页依赖（日常使用不需要 Node）：

```powershell
uv sync --python 3.12 --extra ocr --extra web
```

## 二、日常流程

1. **导入**：文献库页面选择或拖入多个 PDF / DOCX。浏览器只上传你选中的文件，
   网页无法读取你电脑上的其他路径。每个文件单独校验，坏文件会单独列出原因。
2. **后台识别**：导入后立刻返回，识别在后台逐页进行。可以关掉浏览器页签，
   本机服务还在运行就继续识别；服务重启后任务会从检查点恢复。
   异常退出后可能需等待旧任务的租约过期（默认最多约 5 分钟），已完成页会保留。
3. **检索**：全库检索支持中文短词、精确短语、全部包含、任一关键词。
   空格与换行会被忽略，标点也能检索。结果按每页 30 条分页。
4. **核对**：右侧看原页（文件第几页），下方看识别文字。文件页序与印刷页码分开显示，
   印刷页码默认是「未确认」，需要你确认后才算数。
5. **校订**：改错字要写原因。原始识别结果不会被覆盖；旧版本进入历史；
   相关旧摘录自动变成「需复核」，引文本身不会被改写。
6. **保存摘录**：选中文字后保存，引文必须是从所选偏移开始的**精确切片**，
   同一句第二次出现时保存的就是第二次，不会错位。
7. **归类与批量**：在「摘录集」里按文献、分类、集合、核验状态筛选；
   勾选可以跨页保留（翻页不清空），换筛选会清空选择并说明原因，
   以免把旧选择带进新范围。勾选后可以批量设置分类、加入集合，
   从当前集合移除。**核验状态必须逐条人工确认，没有批量接受。**

## 三、集合与资料导出

### 集合（专题）

- 「摘录集 → 管理集合」里新建与改名；集合**没有删除接口**，需要下线时改名为「（归档）」；
- 一条摘录可以属于多个集合；集合只影响归类，不改变引文、核验状态与校订历史；
- 在集合筛选下勾选摘录后点「移出当前集合」，只是取消归类，摘录本身不会被删。

### 导出资料集

「导出资料集」分两步：**先预览，再生成**。

- 范围二选一：全部匹配摘录（包含所有页，不受每页 30 条限制）
  或仅已选条目中符合条件的摘录；来源、分类和集合沿用列表，核验状态以下方选择为准；
- 核验口径默认**仅已接受**；要包含待核验 / 需复核 / 已拒绝必须显式选「全部核验状态」，
  这些条目在文件里会带「复核前不应引用」的说明；
- 预览显示实际条数与状态分布。**预览之后如果有人校订原文、改核验状态或改书目，
  生成会返回 409 并要求重新预览**，不会拿旧判断出文件；
- 四种格式 `CSV / JSON / Markdown / DOCX` 都是资料集：逐条包含摘录 ID、单元与文献 ID、
  书名/作者/年份/版本卷次、原件 SHA-256、文件页与印刷页码及其确认状态、
  记录时的文字版本/哈希/字符偏移、引文、分类、备注、核验状态与核验记录；
  文件里**不包含你电脑上的原件路径**；
- 文件名由服务端按内容摘要决定，下载按 ID 解析，不会写到任意位置；
  同一份内容重复生成得到同一个文件。

## 四、覆盖与任务状态怎么读

覆盖提示的口径（`GET /api/v1/coverage`）：

- `covered_pdf_pages`：当前版本**已建立索引**的文字页 + 你人工确认的空白页；
- `pending_pdf_pages`：还没识别、或者识别了但没有文字的页；
- `failed_pdf_pages`：出错的页；
- `unknown_documents`：页数未知（例如文件损坏）的文献——**不会显示假百分比**；
- `indexed_docx` / `total_docx`：Word 按份统计，不伪造页数。

任务状态：`queued 排队中` → `preparing 准备文件` → `running 识别中` →
（`pausing 正在暂停` → `paused 已暂停`）→ `completed 已完成` /
`partial 部分完成` / `failed 失败`。

- **暂停**在当前页提交之后生效，不会留下半页结果；
- **继续**只做没做完的页，已成功的页不会重做；
- **重试失败页**只重做失败与待处理的页；
- 识别为空（没有返回任何文字）的页会标记为待处理，**不会**被算成成功；
  你可以人工确认它是空白页。

## 五、重新识别

阅读器或文献详情中的重新识别会先生成**候选**，供你对照原页决定是否采用。

1. 选择当前页或文件页范围，选择「省资源配置」或「兼容配置」，提交生成任务。
   范围以 PDF 的文件页序计数，一次最多 1000 页；不使用印刷页码解释范围。
2. 到「识别任务」查看进度。推理完成与人工待核数量分别显示；「完成」不代表已采用。
3. 打开页面，在现用文字、候选文字和旧 OCR 底稿之间切换；差异只表示文字不同，
   需要你对照原页判断。折叠详情可查看实际模型指纹、配置、耗时和内存采样。
4. 「采用」更新机器底稿并保留完整旧版本；「保留现用」记录决定，正文不变。
   候选和旧底稿视图不能保存正式摘录，请先切回现用文字。

生成、失败或保留候选都不会改变现用正文、校订、索引和既有摘录。采用时已有的
人工校订继续生效，包括明确保存的空校订；原文版本发生变化的旧摘录进入「需复核」，
摘录快照保持原样。若生成后页面被校订，采用会提示冲突，需要重新识别或重新核对。

省资源配置逐页运行，识字和方向分类批次为 1、ONNX 线程各 2；初始化时限 120 秒、
单页 60 秒，进程树 RSS/私有内存各限 2.5 GiB。采样峰值不是准确率或整机内存预算。
同一文献库同时只运行一个 OCR 页进程；文字层提取和索引不占识别闸门。
网页仅使用本机已有的模型和依赖，不会自动下载。配置显示不可用时会说明原因。

## 六、数据与备份

工作区目录里的内容：

| 路径 | 内容 |
| --- | --- |
| `sources/` | 不可变原件副本，按内容哈希存放 |
| `litworkbench.sqlite3` | 文献、文字、任务、索引、摘录、集合与导出记录 |
| `staging/` | 上传暂存，任务完成后清理 |
| `artifacts/pages/` | 派生页图 |
| `artifacts/ocr-raw/` | 识别进程的完整结果与资源审计 |
| `artifacts/exports/` | 已生成的摘录资料集文件（按 ID 下载，不接受任意路径） |
| `backups/` | 升级前的数据库备份 |

- 原件按**内容哈希**去重：同一份文件重复上传不会产生第二本，只会补做未完成的页；
- 升级工作区结构前会自动备份到 `backups/`，失败时整体回滚，不会损坏已有摘录；
- 日常备份请先停止服务，再复制整个工作区目录；原件副本、配置与数据库都需要保留。
  `backups/` 里的 `.bak` 只是升级前的数据库快照，不包含原件，也不代表最新进度。

## 七、已知边界（本轮未验证/未实现）

- 网页摘录集已可保存、分类、归入集合、批量整理，并导出 CSV/JSON/Markdown/DOCX 资料集；
  资料集只整理已保存的摘录，**不生成研究结论**；
- **AI 研究（网页配置模型密钥、Agent 运行、报告生成）仍未接入网页**；
- 合计 1000 页的检索与导出性能目标尚未用真实长书验证；
- 四种资料已在真实浏览器下载并解析核对，Word 另经渲染逐页查看；
  当前真实集合只有 1 条摘录，跨页批量行为由合成 65 条测试覆盖，见 [本轮验收](web-task6-acceptance.md)；
- 识别质量仍需用你的真实县志抽样核对，置信度不等于准确率；
- PDFium 页图渲染在独立子进程里完成，如果杀毒软件拦截子进程，页图会失败，
  文字与检索不受影响；
- 服务只监听本机地址，不支持多人同时使用。

## 八、出问题先看这里

| 现象 | 处理 |
| --- | --- |
| 打开是「缺少前端编译产物」页面 | 执行 `npm --prefix web-client install` 与 `npm --prefix web-client run build` |
| 某页一直「待识别」 | 确认已安装 OCR 依赖（`--extra ocr`），然后在任务页「重试失败页」 |
| 页码是「候选」不是「已确认」 | 核对原页后用页码面板改为「已确认」，系统不会自动推断 |
| 保存摘录报 409 | 文字在你编辑期间被改动，页面会保留草稿，重新核对后再保存 |
| 检索提示「资料已更新」 | 有新文字或页码进入索引，自动按相同条件重查第一页 |
| 导出报 409「预览之后内容发生了变化」 | 预览后有人校订、改核验状态或改书目；点「重新预览」再生成 |
| 导出预览显示 0 条 | 当前筛选（默认只含已接受）与显式选择的交集为空；先预览再生成 |
| 批量按钮点不动 | 尚未勾选，或新筛选仍在加载/加载失败；先刷新取得当前条件的结果 |
