## 关键回归

- 复制原件中断不会留下被误认有效的半文件；缓存原件损坏可通过重复导入修复。
- 导入每页保留进度，缺失页不会被判成整书完成；显式 `.doc` 给出转换提示并返回非零退出码。
- 原文、校订与 OCR 重提取保留历史；校订与证据失效标记在同一事务中提交。
- Word 文件创建年份不会当作出版年；空字符串校订也生效。
- Agent 只允许从读过的版本和文字范围摘录；长单元可分段读取。校订后需重新阅读。
- 同一句话重复出现时，保存实际已读位置的偏移，不强制指向第一次出现。
- 协议类型错误可反馈恢复；重复跨行引文按原文切片去重。
- 动作已保存、对话或最终报告尚未保存时中断，恢复可补齐；已验证的 finish 可以不调用模型而完成恢复。
- 不存在、其他任务、拒绝或失效证据不能把报告标成有效。人工接受摘录不等于研究结论正确。
- 三种报告格式核对书名、编者、年版卷、印刷页码、原文单元及原件哈希；5011 条证据全部导出，无固定 5000 条截断。
- 模拟服务的假密钥及错误响应中的假密钥不写入任务、配置、报告或数据库。

## 验收范围

资料全部明确标注为合成测试数据。模拟 HTTP 服务只在测试中使用；生产 Agent 调用用户配置的兼容接口。

尚未取得用户真实县志或实际 API，因此未验证真实文献识别准确率、供应商模型行为、长书吞吐量和多人并发。首版为单用户 CLI，无 GUI、团队协作、向量检索和模型权重训练。提示词能指导模型，结构化动作和引文校验提供可执行边界；不宣称完全消除提示词注入或自动证明历史结论。
