# 本地文献工作台：第一版设计

## 已确认

- 通用文档、文献工作台，首批使用场景是从县志、丛书中查找文化遗产出处，摘录、分类、分析、总结和输出。
- 本地优先，团队功能后续；提供 CLI，允许用户接入自己的 AI API。
- 可调整提示词、术语、分类体系、研究流程和输出要求；此处微调指工作台配置。
- 主要输入为建国后新县志的扫描 PDF，也有文本 PDF 和 Word；首批不涉及繁体竖排。
- 原文、校订、模型解释分别保存，成果可以回到原件核验。

## 本次实施决定

交付可安装的 Python CLI（命令 `lit`，模块 `litworkbench`），而非图形界面。使用本地 SQLite 和文件目录。默认导入、检索、摘录不需要 API；只有显式发起或恢复研究任务才请求配置的模型。支持 OpenAI-compatible chat completions 的自定义 base URL、模型名和环境变量密钥；不自动读取本机其他应用的凭据。

OCR 使用可选的 RapidOCR + ONNX Runtime CPU；文本提取、页面渲染使用 pypdfium2，DOCX 使用 python-docx。模型权重首次可能需下载，推理在本地进行。未装 OCR 时标明待识别，不能把无文本扫描件宣称为已完成。旧 `.doc` 给出先转为 `.docx` 的明确提示。

第一版中文检索采用可验证的本地文字匹配，支持短中文词、跨换行匹配和字面标点；Agent 通过多次查询、方案中的别名/术语扩展和阅读上下文开展研究。向量检索、复杂表格结构还原、语义版面分析、跨页自动拼接和团队协作不在本次交付中。

## 数据与出处

- 文献：内容哈希、不可变原件副本、文件类型、书名、作者/编者、年份、版本、卷次、导入状态。
- 原文单元：PDF 的一页，或 DOCX 的段落/表格（按文档顺序）；稳定 ID、原始文字、校订文字、校订历史、提取方法、质量/待核验状态。
- PDF：文件页序（1 起）与可手动维护的印刷页码分开。页图可按需渲染。OCR 行框与置信度保留，明确像素坐标及渲染尺寸。文字 PDF 至少有可靠页面定位，不伪造行框。
- DOCX：按段落/表格定位，不编造固定页码。保留标题路径和表格文字顺序。
- 摘录：引用的原文单元、准确文字与偏移、取自原始还是校订版本、版本快照、分类、分析备注、核验状态。拒绝不属于原文的引文。校订不会覆盖原始识别结果；相关旧摘录标记待复核。
- 研究任务：问题、研究方案快照、状态、步骤记录、模型对话、证据和结构化报告。密钥不入库、不写日志。

## 工作流

1. 初始化文献库和可编辑 TOML 配置，内置通用、文化遗产两种方案。
2. 导入文件或目录，内容哈希去重。每页保存结果，重复导入能够补做待 OCR/失败单元。混合 PDF 按页判断；支持 auto/off/force OCR。
3. 搜索命中后读取页/段落，必要时渲染原件页图；可修订书目信息、印刷页码和识别文字。
4. 保存并审核摘录。检索、人工摘录和导出在无 API 时可用。
5. 配置模型后启动 Agent：动态选择搜索、阅读、保存摘录、完成报告；设步骤上限，异常保存检查点，支持恢复。
6. 导出 Markdown、JSON、DOCX 报告，包含引文、完整定位、核验状态和待解决问题。证据亦可独立导出 JSON/CSV。

Agent 的工具是工作台内置的有限动作，不开放任意 shell、任意文件读取或任意 URL 请求。文献内容和工具结果作为资料处理，不作为新指令。用户可通过配置限制可用工具、最大步骤、分类、提示词、别名、报告章节。历史任务保留启动时方案，后改方案不悄悄改变旧任务。

## 报告的可信边界

模型必须用结构化 claim + evidence_ids 提交研究结论；程序检查 ID 属于当前任务、引文来自已读取原文、证据未被拒绝。没有证据时只输出未找到结果与待解决问题。可追溯性不等于结论已经经人工认定，报告显示待核验状态。来源文件名、文本和模型回答都不得进入可执行命令。

## 验收

- CLI 在 Windows 的中文和空格路径下真实运行；安装、帮助、初始化、导入、检索、读取、摘录、校订、审核、任务、恢复、导出均有可运行用例。
- 用明确标识为合成的资料验证文本 PDF、图片 PDF、混合 PDF、DOCX 段落/表格；OCR 至少实际识别一份中文扫描样例。
- 无 API 时基础工作可完成；模拟兼容 HTTP 服务验证多轮 Agent、协议错误、无效引文/引用、步骤限额和恢复，不能把此测试称为真实供应商验收。
- 独立检查原件哈希、页码、导入幂等、短中文检索、SQL 通配符、引用完整性、修订后的证据状态、密钥不落盘。
- 尚未取得用户真实县志和 API，因此真实资料质量、识别准确率、长书性能与实际供应商兼容性单独标记为未验证。
