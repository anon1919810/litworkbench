# Codex 远程内容工具 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans。沿用用户批准的OpenCode实施、Codex验收方式。

**Goal:** 真实Codex通过受保护的Streamable HTTP MCP读取文献、创建摘录并编辑同一笔记工作区。

**Architecture:** 官方Python MCP SDK作为ASGI子应用挂入现有FastAPI，顶层lifespan启动SDK会话管理器。MCP身份从阶段B的PAT校验获得，工具直接调用阶段A内容服务，origin固定为codex，不能让输入伪造身份。

**Tech Stack:** Python MCP官方SDK（兼容版本锁定）、FastAPI、现有SQLite内容服务、Codex客户端。

**Spec:** `docs/superpowers/specs/2026-10-26-cloud-workspace-codex-design.md` 第7–8节；阶段A/B实施契约。

## Global Constraints

- 工具固定为设计列出的10个：workspace_search/page_get/page_create/page_update_properties/page_edit_blocks/page_get_history/document_get/unit_read/evidence_create/evidence_get。
- 无删除、归档、历史恢复、OCR采用、校订采用或核验工具。只读PAT不能调用任何写工具，编辑PAT也不能绕过上述边界。
- 默认输出最多24000字符；分页游标不透明且绑定对象/修订，截断显式标识；按Unicode代码点续读，版本变更报冲突，不拼接两版文字。
- 所有写入修订、幂等和历史复用notes；不能通过HTTP回调自己的网页API，也不另建数据副本。
- 不改全局Codex配置、不把PAT放配置正文；先使用单次Codex CLI配置和进程环境完成隔离验收。

## Review Focus

1. 挂载后SDK lifespan未启动、/mcp被SPA吞掉或Host allowlist拒绝真实域名。
2. cookie代替PAT、只读令牌写入、撤销后旧会话继续调用。
3. 编号页游标过期、Unicode截断或超大嵌套段落被误报完整。
4. 写入重试重复创建对象、替换块旁路删除受保护证据。
5. 源文献指令被当工具授权、客户端origin冒充web或伪造核验状态。
